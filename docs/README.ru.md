# SoraMod

[English](../README.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Deutsch](README.de.md) · [Español (España)](README.es-es.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Polski](README.pl.md) · [Português (Brasil)](README.pt-br.md) · [Русский](README.ru.md) · [简体中文](README.zh-cn.md) · [Español (Latinoamérica)](README.es-419.md) · [正體中文](README.zh-tw.md)

Трейнер для сюжетного режима GTA V Enhanced от MinamotoDev. Поддерживает клавиатуру, мышь и геймпад; для меню используются встроенные шрифты.

[Скачать последнюю версию](https://github.com/MinamotoDev/SoraMod/releases/latest) · [Примечания к выпуску](../RELEASE_NOTES.md)

## Возможности

- Неуязвимость, восстановление здоровья и брони, снятие уровня розыска, пополнение боеприпасов и ремонт транспорта.
- Создание транспорта по категориям, из полноэкранной галереи, случайным выбором или по коду модели, включая доступные в установленной игре модели только для Online.
- Закрепление транспорта с сохранением позиции, номера, цветов и распространённых модификаций; дистанционное открепление, телепортация внутрь и отметки на карте.
- Телепортация к точке на карте; изменение времени, остановка часов и смена погоды.
- Язык меню соответствует языку игры.

## Установка

1. Добавьте `-nobattleye` в файл `args.txt` в папке игры.
2. Установите [Script Hook V](https://www.dev-c.com/gtav/scripthookv/) и ASI Loader, совместимые с вашей версией игры.
3. Скачайте `SoraMod-0.4.1-win-x64.zip` и скопируйте `SoraMod.asi` и папку `SoraMod` в папку игры.
4. Запустите сюжетный режим и нажмите `F7`, чтобы открыть меню.

Требуются 64-разрядная Windows 10 или новее и GTA V Enhanced. Только сюжетный режим. Перед обновлением закройте игру и замените файлы мода; настройки и сохранённые данные находятся в `SoraMod/settings.ini` и `SoraMod/data`.

## Управление

| Действие | Клавиатура | Геймпад |
| --- | --- | --- |
| Открыть / скрыть | F7 | Удерживать RB / R1, затем крестовина вправо |
| Выбор пункта списка | Вверх / Вниз | Крестовина вверх / вниз |
| Следующая страница списка | Вправо / Page Down | Крестовина вправо / RB |
| Предыдущая страница; назад с первой страницы | Влево / Backspace | Крестовина влево |
| Выбор карточек в полноэкранном режиме | Стрелки: вверх/вниз по строкам, влево/вправо к соседней карточке | Крестовина вверх / вниз / влево / вправо |
| Подтвердить | Enter | A / Крестик |
| Родительское меню; из главного меню в игру | Esc | B / Круг |
| Вкладки категорий в полноэкранном режиме | Tab / Shift+Tab | RB / LB (R1 / L1) |
| Сразу на предыдущую страницу | Page Up | LB / L1 в обычных списках |

## Данные транспорта

«Создать по коду модели» принимает коды вроде `adder` и `oppressor2`. Поле ввода изначально пустое. Доступность моделей зависит от установленной версии игры.

Откройте «Закреплённый транспорт», находясь в машине, чтобы закрепить или открепить её. Записи находятся в `SoraMod/data/pinned-vehicles.dat`. Позиция и модификации сохраняются каждые 5 секунд, а при закреплении и откреплении — сразу. После перезапуска игры транспорт восстанавливается при приближении к сохранённому месту или выборе телепортации внутрь. Файл `.bak` рядом с данными используется для восстановления после повреждения. Открепление всего транспорта освобождает его без удаления из сцены.

## Удаление и сообщения об ошибках

Для удаления мода удалите `SoraMod.asi` и папку `SoraMod`. Если планируете использовать мод снова, сначала сохраните копию `SoraMod/data`. В сообщении об ошибке укажите версию игры, версию Script Hook V, код модели и приложите `SoraMod/SoraMod.log`.

## Сборка

Запустите `tools/build.ps1 -Cxx <путь к g++.exe>` с MinGW-w64 GCC x64 (C++17). Для повторного создания глифов нужны Python, Pillow, fontTools, файлы шрифтов, `research/vehicles.json` и `research/natives.json`; запустите `tools/build-assets.py`. Тесты вне игры запускаются через `tests/run.ps1`; настройте пути к инструментам в скриптах. Источники ресурсов: [THIRD_PARTY.md](../THIRD_PARTY.md).
